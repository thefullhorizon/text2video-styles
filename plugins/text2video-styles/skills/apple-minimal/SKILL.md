# 极简苹果风 · Apple Minimal

用户说「极简苹果风」+ 文案 → 不追问，直接出片。参数已写死在 `template.html` / `make_video.py`，不要擅自修改；用户要求调参时先改参数再出片。

## 出片步骤

1. **拆文案**：一屏一行，按标点断开，每行放进 `lines`；结尾完整文案的分行放进 `final`（省略则用 `lines`）。
   ```json
   {"lines":["如果你做事的动力来自于外在，","你永远不会有耐心；","如果你做事的动力来自于内心，","那你永远不会有对手！"]}
   ```
2. **首次准备**（在本目录）：`npm install`（安装霞鹜文楷 OFL 字体）；需要 Python3 + `pip install playwright && playwright install chromium`、ffmpeg、思源黑体（Noto Sans CJK SC，macOS 会自动回退苹方）。
3. **渲染**：`python3 make_video.py spec.json 输出.mp4`
   总时长 = 0.15 + 1.8 × 行数 + 2.5 秒（4 行 ≈ 9.9 秒），约每秒成片需 6～8 秒渲染。
4. **自查**：抽 3～4 帧，确认文字不出框、背景不露边、结尾文字清晰；交付时告知视频时长。

## 固定参数

| 项 | 参数 |
|---|---|
| 画幅 | 1080×1920，30fps，H.264 + AAC |
| 背景 | `assets/bg.jpg` 青蓝-松石绿弥散渐变（由 `scripts/gen_apple_minimal_bg.py` 程序生成）；远景层随镜头轻微俯仰/环绕产生视差，全程极缓推近 |
| 玻璃框 | 紧凑单行横条，圆角 24px，白 13% 透明，内描边 + 斜切高光；实体 3D 厚度约 60px（四个侧面，前亮后暗） |
| 侧面显隐 | 随倾斜角度显示，正对屏幕时完全隐藏（停留阶段为纯 2D） |
| 暖色光带 | 135° 从左上扫到右下，香槟色亮芯，入场后 0.3～1.2 秒 |
| 行内文字 | 思源黑体 Light 300，纯白，68px，单行最宽 880px 自动缩字号，带极淡投影 |
| 每行 1.8 秒 | 入场 0.5 秒（2.5D：偏转 −42°、仰角 −18°、旋转 −4° 转正并淡入）→ 停留 0.8 秒（纯 2D 正对屏幕）→ 粒子散去 0.5 秒（中心向四周椭圆消融，约 700 颗暖金光点分深度飞散） |
| 结尾 | 最后一行粒子汇聚成完整文案：霞鹜文楷 Regular 64px，行高 1.6，居中，#F5F5F0，无光晕无框；清晰后停约 1.4 秒 |
| 配乐 | `assets/starlight.m4a`，0.2 秒淡入、结尾 1.1 秒淡出，超长自动循环 |

## 文件

- `template.html` 页面模板（占位符 `__CARDS__ __IDS__ __FINAL__ __C0__ __C1__ __F0__ __F1__ __TOTAL__`）
- `card.tpl` 单个玻璃框模板
- `make_video.py` 生成页面 → Playwright 逐帧截图 → ffmpeg 合成
- `assets/` 背景图与配乐
