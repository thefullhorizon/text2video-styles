# 文本Power 经典风 · TextPower Classic

## 出片步骤

1. **拆文案**：一屏只放一句话；句内按说话停顿断句，每个断句标注角色：
   - `lead` 前导短语（白色 Medium 中号）
   - `conn` 连接词，如「就是」「值得」（灰色 Regular 小号）
   - `accent` 每屏关键词（彩色 Bold 大号），每屏恰好一个、放最后
   ```json
   {"name":"清醒的人不合群","screens":[
    [{"t":"清醒的人","role":"lead"},{"t":"不合群","role":"accent"}],
    [{"t":"干净的人","role":"lead"},{"t":"不扎堆","role":"accent"}],
    [{"t":"独来独往的人","role":"lead"},{"t":"值得","role":"conn"},{"t":"深交","role":"accent"}]]}
   ```
2. **依赖**：Python3 + Pillow + numpy、ffmpeg、思源黑体 Noto Sans CJK（ttc）。
3. **渲染**：`python3 make_video.py spec.json out/`，输出 `out/<name>.mp4` 和 `out/<name>_封面.png`。
4. **发布文案**：标题优先「为什么……？」式问句钩子；标签 #思维 #成长 #认知 + 1～2 个主题标签。

## 固定参数

| 项 | 参数 |
|---|---|
| 画幅 | 1080×1920，30fps |
| 背景 | 暖棕径向渐暗：中心 (60,38,37) → 边缘 (18,15,18) |
| 字体 | 思源黑体 SC |
| 颜色 | 白 (240,236,230)；灰 (178,170,163)；关键词按屏轮换 橙 #E8552F / 绿 #5DB98A / 蓝 #5AA0DC / 紫；末屏关键词金黄 #FFCC26 |
| 装饰 | 非末屏关键词两侧细竖线；末屏关键词下划线 |
| 动效 | 短语 0.3 秒淡入上浮；关键词 0.22 秒由 1.18 倍缩回淡入；屏间 0.3 秒淡出上移 |
| 节奏 | 卡 Starlight 120BPM：首断句 0 秒，第二个 +1.0 秒，之后每个 +0.5 秒；非末屏停 1.5 秒换屏，末屏停 1.25 秒 |
| 封面 | 文案短时直接展示完整文案；不加署名 |
| 配乐 | `assets/starlight.m4a`，首尾淡入淡出 |
